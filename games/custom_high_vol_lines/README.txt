Custom High Volatility 10 Lines Game

This game was generated based on your requirements:
1. 5x3 Reel Grid
2. 10 Paylines (Fixed)
3. High Volatility (Low Base Game RTP, High Free Game potential)
4. Free Spins Feature (Triggered by 3, 4, or 5 Scatters)

Files:
- game_config.py: The main configuration. You can adjust paytable and RTP here.
- reels/BR0.csv & FR0.csv: The reel strips. FR0 is richer than BR0.
- gamestate.py: The game logic loop.
- run.py: Script to run simulations locally.

To run more simulations:
    python run.py

To adjust volatility:
    Modify 'game_config.py' paytable values or the reel strips in 'reels/'.
